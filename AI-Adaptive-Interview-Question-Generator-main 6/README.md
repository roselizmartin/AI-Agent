# 🤖 AI-Adaptive Interview Question Generator

An AI-powered web application that generates technical interview questions based on the selected subject and difficulty level. The system helps students and job seekers prepare for technical interviews by providing relevant questions and evaluating their performance.

---

## 📌 Project Overview

The AI-Adaptive Interview Question Generator is designed to assist users in practicing technical interview questions. It uses Machine Learning techniques to generate questions from different Computer Science subjects and adapts the difficulty level based on user selection.

The project aims to provide an interactive and personalized interview preparation experience.

---

## ✨ Features

- 🔐 User Registration and Login
- 📚 Subject Selection (DBMS, Operating Systems, Computer Networks, DSA)
- 🎯 Difficulty Levels (Easy, Medium, Hard)
- 🤖 AI-Based Interview Question Generation
- ✅ Answer Evaluation
- 📊 Performance Analysis
- 📈 Adaptive Learning Experience

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/AI-Adaptive-Interview-Question-Generator.git
```

### 2. Navigate to the Project Folder

```bash
cd AI-Adaptive-Interview-Question-Generator
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app_Version3.py
```
